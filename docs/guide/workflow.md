# GeoSave workflow

> **Status:** This is a workflow skeleton. Commands and configuration examples will be added after pipeline, dataset, and model interfaces settle.

## Planned stages

1. Create a workspace with the `geosave` CLI.
2. Define spatial anchors and inspect source coverage.
3. Ingest and preprocess geospatial layers.
4. Validate samples before scaling dataset creation.
5. Build and version the dataset.
6. Configure model, task, and training data.
7. Train and evaluate.
8. Run prediction and reconstruct raster outputs.
9. Register or publish approved artifacts.

## Current guidance

Use generated templates as editable starting points. Verify behavior against current source while redesign is active. Avoid depending on provisional `GeoStack`, `GeoSample`, pipeline, dataset, or model interfaces until their contracts are declared stable.
